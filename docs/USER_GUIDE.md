## 시작하기

### 회원가입

KPL에 참여하려면 먼저 계정을 만들어야 합니다.

#### 방법 1: 이메일로 가입

1. 메인 페이지 우측 상단 **"Sign In"** 클릭
2. **"이메일"** 탭 선택
3. 하단의 **"계정이 없으신가요? 회원가입"** 링크 클릭
4. 정보 입력:
   - **이메일**: 유효한 이메일 주소
   - **비밀번호**: 6자 이상
   - **PSN ID**: PlayStation Network ID (고유해야 함)
5. **"회원가입"** 버튼 클릭
6. 이메일 인증 메일 확인 후 링크 클릭

#### 방법 2: Google 계정으로 가입

1. 메인 페이지 우측 상단 **"Sign In"** 클릭
2. **"Google"** 탭 선택
3. **"Continue with Google"** 버튼 클릭
4. Google 계정 선택 및 권한 승인
5. PSN ID 입력 페이지에서 PlayStation Network ID 입력
6. **"완료"** 클릭

### 로그인

1. 우측 상단 **"Sign In"** 클릭
2. 이메일 또는 Google 계정으로 로그인
3. 로그인 성공 시 네비게이션 바에 프로필 아이콘 표시

## 팀 생성 신청

자신만의 팀을 만들어 KPL에 참가할 수 있습니다!

### 신청 조건

- KPL 계정이 있어야 합니다
- 로그인 상태여야 합니다
- 한 시즌에 여러 팀을 신청할 수 있습니다

### 신청 방법

1. 네비게이션 바에서 **"Teams"** → **"Create Team"** 클릭
2. 팀 정보 입력:

   **필수 정보**:
   - **팀 이름**: 고유한 팀 이름 (3~20자)
   - **컨퍼런스**: Western 또는 Eastern Conference 선택

   **선택 정보**:
   - **팀 로고**: 이미지 파일 업로드
     - 파일 형식: PNG, JPG, WEBP
     - 최대 크기: 2MB
     - 권장 크기: 512x512px (정사각형)
     - 투명 배경 권장

3. 로고 업로드 시 미리보기 확인
4. **"팀 생성 신청"** 버튼 클릭
5. 신청 완료 메시지 확인

### 신청 후

- 관리자가 신청을 검토합니다
- 승인/거부 결과는 `/teams/my-requests`에서 확인할 수 있습니다
- 승인되면 자동으로 팀 주장이 됩니다

## 내 신청 확인

### 신청 현황 보기

1. 네비게이션 바에서 **"Teams"** → **"My Requests"** 클릭
2. 내가 신청한 모든 팀 목록 확인

### 신청 상태

**🟡 Pending (대기 중)**
- 관리자가 아직 검토하지 않음
- 승인/거부 대기 중

**🟢 Approved (승인됨)**
- 팀이 생성되었습니다!
- 당신이 팀 주장입니다
- 승인자와 승인 날짜 표시

**🔴 Rejected (거부됨)**
- 신청이 거부되었습니다
- 거부 사유 확인 가능
- 수정 후 다시 신청 가능

### 신청 카드 정보

각 신청 카드에는 다음이 표시됩니다:
- 팀 이름
- 시즌
- 컨퍼런스
- 로고 미리보기
- 신청 날짜
- 상태 배지
- 거부 사유 (거부된 경우)
- 승인 정보 (승인된 경우)

## 경기 일정 보기

### 전체 일정 확인

1. 네비게이션 바에서 **"Schedule"** 클릭
2. 현재 시즌의 모든 경기 확인

### 일정 화면 구성

**날짜별 그룹**:
- 경기가 날짜별로 그룹화되어 표시됩니다
- 각 날짜의 경기 개수 표시 (예: 5경기)

**경기 정보**:
- 🕐 **시간**: 경기 시작 시간 (보통 22:40 또는 23:20)
- 🏀 **매치업**: 홈팀 vs 어웨이팀
- 📊 **상태**:
  - `예정` - 아직 시작하지 않음
  - `LIVE` - 현재 진행 중 (빨간색, 깜빡임)
  - `종료` - 경기 종료 (점수 표시)
  - `취소` - 경기 취소
- 🔢 **점수**: 종료된 경기의 최종 점수

### 필터 사용

**이전 경기 숨기기**:
- 우측 상단 토글 버튼 클릭
- 오늘 이전 경기를 숨깁니다
- 다시 클릭하면 모든 경기 표시

### 경기 상세보기

1. 경기 행을 클릭
2. 경기 상세 정보 다이얼로그 열림:
   - 경기 날짜 및 시간
   - 팀 정보 (로고, 이름)
   - 경기 상태
   - 최종 점수 (종료된 경기)
   - 게임 비밀번호 (있는 경우)

## 순위표 확인

### 순위표 보기

1. 네비게이션 바에서 **"Standings"** 클릭
2. 현재 시즌의 팀 순위 확인

### 컨퍼런스별 분리

**Western Conference**:
- 파란색 배지
- 서부 컨퍼런스 팀들

**Eastern Conference**:
- 빨간색 배지
- 동부 컨퍼런스 팀들

### 순위 정보

각 팀의 순위표에는 다음이 표시됩니다:
- **순위**: 컨퍼런스 내 순위
- **팀 로고 & 이름**
- **W-L**: 승-패 기록
- **PCT**: 승률 (Win Percentage)
- **GB**: Games Behind (1위와의 게임 차)
- **PF**: Points For (득점)
- **PA**: Points Against (실점)
- **DIFF**: 득실차 (PF - PA)

### 정렬 기준

순위는 다음 우선순위로 결정됩니다:
1. 승률 (높을수록 상위)
2. 승수 (많을수록 상위)
3. 득실차 (높을수록 상위)
4. 득점 (많을수록 상위)

## 선수 통계 보기

### 통계 리더보드

1. 네비게이션 바에서 **"Stats"** 클릭
2. 카테고리별 상위 선수 확인

### 통계 카테고리

**8개 주요 카테고리**:
- 🏀 **PPG** (Points Per Game): 경기당 득점
- 🎯 **RPG** (Rebounds Per Game): 경기당 리바운드
- 🤝 **APG** (Assists Per Game): 경기당 어시스트
- 🛡️ **SPG** (Steals Per Game): 경기당 스틸
- 🚫 **BPG** (Blocks Per Game): 경기당 블록
- 🎯 **FG%** (Field Goal %): 야투 성공률
- 🎯 **3P%** (3-Point %): 3점슛 성공률
- 🎯 **FT%** (Free Throw %): 자유투 성공률

### 리더보드 정보

각 선수 카드에는:
- 순위 (1~10위)
- 선수 PSN ID
- 소속 팀 (로고 + 이름)
- 해당 카테고리 수치

## 프로필 관리

### 내 프로필 보기

1. 우측 상단 프로필 아이콘 클릭
2. **"Profile"** 선택
3. 내 정보 확인:
   - PSN ID
   - 이메일
   - 가입일
   - 소속 팀 (있는 경우)
   - 역할 (User, Admin, Staff)

### 프로필 수정

1. 프로필 페이지에서 **"Edit Profile"** 버튼 클릭
2. 수정 가능 항목:
   - **PSN ID**: 고유한 ID로 변경 가능
   - **아바타 이미지**: 프로필 사진 업로드
3. **"저장"** 클릭

### 비밀번호 변경

(이메일 가입자만 해당)

1. 로그아웃
2. 로그인 페이지에서 **"비밀번호를 잊으셨나요?"** 클릭
3. 이메일 입력 후 재설정 메일 확인
4. 새 비밀번호 입력

## 자주 묻는 질문

### Q1. 회원가입은 무료인가요?

네, KPL 계정 생성은 완전히 무료입니다.

### Q2. PSN ID를 변경할 수 있나요?

네, 프로필 페이지에서 언제든지 변경 가능합니다. 단, 중복된 PSN ID는 사용할 수 없습니다.

### Q3. 한 사람이 여러 팀을 만들 수 있나요?

신청은 여러 개 가능하지만, 관리자 승인 정책에 따라 다를 수 있습니다.

### Q4. 팀 로고를 나중에 변경할 수 있나요?

팀이 승인된 후에는 팀 주장이 관리자에게 요청하여 변경할 수 있습니다.

### Q5. 팀 신청이 얼마나 걸리나요?

일반적으로 24~48시간 이내에 관리자가 검토합니다. 급한 경우 관리자에게 문의하세요.

### Q6. 팀 신청이 거부되었어요. 다시 신청할 수 있나요?

네, 거부 사유를 확인하고 수정 후 다시 신청할 수 있습니다.

### Q7. 경기 일정은 언제 업데이트되나요?

관리자가 시즌 일정을 공지하면 즉시 확인할 수 있습니다. 보통 매주 화/목/일 22:40, 23:20에 경기가 있습니다.

### Q8. 내 통계는 어디서 볼 수 있나요?

Stats 페이지에서 카테고리별 상위 10명이 표시됩니다. 전체 통계는 향후 추가 예정입니다.

### Q9. 팀원은 어떻게 추가하나요?

현재는 관리자에게 요청하여 로스터에 추가할 수 있습니다. 팀 관리 기능은 향후 추가 예정입니다.

### Q10. Google 계정으로 가입했는데 비밀번호를 설정할 수 있나요?

Google OAuth로 가입한 경우 별도의 비밀번호가 없습니다. Google 계정으로만 로그인 가능합니다.

### Q11. 탈퇴하고 싶어요

현재는 자동 탈퇴 기능이 없습니다. 관리자에게 문의하여 계정 삭제를 요청하세요.

### Q12. 모바일에서도 사용할 수 있나요?

네, KPL은 모바일 반응형으로 제작되어 스마트폰과 태블릿에서도 사용 가능합니다.

## 💡 팁과 권장사항

### 팀 생성 신청
- **팀 이름**: 독창적이고 기억하기 쉬운 이름 선택
- **로고**: 고품질 이미지 사용 (흐릿한 이미지는 거부될 수 있음)
- **컨퍼런스**: 친구들과 같은 컨퍼런스 선택 시 자주 대결 가능

### 경기 참여
- 경기 일정을 미리 확인하고 시간 맞추기
- 게임 비밀번호가 있는 경기는 미리 메모
- LIVE 경기는 실시간으로 진행 중이니 관전 가능

### 순위 올리기
- 꾸준히 참여하여 승수 쌓기
- 팀원들과 협력하여 전략 수립
- 통계 리더보드 목표 세우기

### 커뮤니티
- 디스코드 또는 커뮤니티 채널 참여
- 다른 팀과 친선 경기 주선
- 시즌 종료 후 시상식 참여

## 🎮 게임 가이드 (NBA 2K)

### 경기 준비

1. **게임 설정**:
   - NBA 2K Online 모드 실행
   - 매치메이킹 또는 비공개 방 생성
   - 게임 비밀번호 입력 (제공된 경우)

2. **팀 선택**:
   - 자신의 KPL 팀에 해당하는 커스텀 로스터 선택
   - 5명 전원 준비 완료

3. **경기 진행**:
   - 정해진 시간에 시작 (22:40 또는 23:20)
   - 4쿼터 진행
   - 최종 점수 기록

### 경기 후

1. **결과 보고**:
   - 팀 주장 또는 관리자가 점수 입력
   - 개인 통계 기록 (PTS, REB, AST 등)

2. **순위 확인**:
   - KPL 사이트에서 업데이트된 순위표 확인
   - 다음 경기 일정 확인
