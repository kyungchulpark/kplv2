## 관리자 대시보드 개요

### 접속 방법

1. KPL 사이트에 로그인합니다
2. 브라우저 주소창에 `/admin` 입력 또는 네비게이션에서 "Admin" 클릭
3. Admin 역할이 없는 경우 접근이 거부됩니다

### 대시보드 구성

관리자 대시보드는 6개의 주요 섹션으로 구성됩니다:

- **Dashboard** - 전체 현황 한눈에 보기
- **Seasons** - 시즌 생성 및 관리
- **Teams** - 팀 생성, 수정, 삭제
- **Team Requests** - 팀 생성 신청 승인/거부
- **Matches** - 경기 일정 및 결과 관리
- **Upload Schedule** - Excel로 경기 일괄 등록

## 시즌 관리

### 새 시즌 만들기

1. 좌측 메뉴에서 **Seasons** 클릭
2. 우측 상단 **"New Season"** 버튼 클릭
3. 다이얼로그에서 정보 입력:
   - **시즌 이름**: 예) "2K26 1st Season"
   - **버전**: 예) "v1.0" (선택사항)
   - **시작일**: 시즌 개막일 (필수)
   - **종료일**: 시즌 종료일 (선택사항)
   - **Playoff Cutoff**: 플레이오프 진출 팀 수 (기본 8팀)
4. **"생성"** 버튼 클릭

### 시즌 수정

1. 시즌 카드에서 **"Edit"** 버튼 클릭
2. 정보 수정 후 **"수정"** 클릭
3. ⚠️ 주의: 시즌 ID는 변경할 수 없습니다

### 시즌 활성화

한 번에 하나의 시즌만 활성화할 수 있습니다.

1. 비활성 시즌 카드에서 **"Activate"** 버튼 클릭
2. 자동으로 기존 활성 시즌은 비활성화됩니다
3. 활성 시즌에는 빨간 테두리와 "Active" 배지가 표시됩니다

**활성 시즌의 역할**:
- 공개 페이지에서 표시되는 기본 시즌
- 팀/경기 관리 페이지의 기본 필터
- 팀 생성 신청이 연결되는 시즌

## 팀 관리

### 새 팀 만들기

1. 좌측 메뉴에서 **Teams** 클릭
2. 우측 상단 **"Add Team"** 버튼 클릭
3. 다이얼로그에서 정보 입력:
   - **팀 이름**: 고유한 팀 이름 (필수)
   - **컨퍼런스**: Western 또는 Eastern Conference (필수)
   - **주장**: 드롭다운에서 선택 (선택사항)
   - **팀 로고**: 이미지 파일 업로드 (PNG, JPG, WEBP, 최대 2MB)
4. **"생성"** 버튼 클릭

**초기값**:
- 승-패: 0-0
- 득점/실점: 0
- 로스터: 빈 상태

### 팀 정보 수정

1. 팀 테이블에서 **"Edit"** 버튼 클릭
2. 다이얼로그에서 정보 수정:
   - 팀 이름
   - 컨퍼런스
   - 주장
   - 로고
3. ⚠️ 주의: 승-패 기록과 점수는 경기 결과 입력으로만 변경됩니다

### 팀 삭제

⚠️ **경고**: 팀 삭제 시 다음 데이터가 함께 삭제됩니다:
- 팀 로스터 (선수 명단)
- 관련된 모든 경기
- 경기 통계 데이터

1. 팀 테이블에서 **"Delete"** 버튼 클릭
2. 확인 다이얼로그에서 **"확인"** 클릭
3. 되돌릴 수 없으므로 신중히 결정하세요

### 팀 로고 관리

**로고 업로드 규칙**:
- 파일 형식: PNG, JPG, WEBP
- 최대 크기: 2MB
- 권장 크기: 512x512px (정사각형)
- 투명 배경 권장 (PNG)

**로고 변경**:
1. 팀 Edit 다이얼로그 열기
2. 파일 선택 버튼 클릭
3. 새 이미지 선택
4. 미리보기 확인
5. 저장

## 팀 신청 관리

### 신청 목록 확인

1. 좌측 메뉴에서 **Team Requests** 클릭
2. 3개의 탭으로 구분:
   - **Pending**: 대기 중인 신청
   - **Approved**: 승인된 신청
   - **Rejected**: 거부된 신청

### 신청 정보 확인

각 신청 카드에는 다음 정보가 표시됩니다:
- 팀 이름
- 시즌
- 컨퍼런스
- 신청자 (PSN ID, 이메일)
- 팀 로고 미리보기
- 신청 날짜

### 팀 신청 승인

1. **Pending** 탭에서 신청 확인
2. **"Approve"** 버튼 클릭
3. 확인 다이얼로그에서 내용 확인:
   - 새로운 팀이 생성됩니다
   - 신청자가 주장으로 설정됩니다
4. **"승인"** 버튼 클릭

**승인 후 변경사항**:
- `teams` 테이블에 새 팀 추가
- 신청자가 `captain_id`로 설정
- 신청 상태가 `approved`로 변경
- 승인자와 승인 일시 기록

### 팀 신청 거부

1. **Pending** 탭에서 신청 확인
2. **"Reject"** 버튼 클릭
3. 거부 사유 입력 (필수):
   - 명확하고 구체적으로 작성
   - 예: "팀 이름이 부적절함", "이미 동일한 팀이 존재함"
4. **"거부"** 버튼 클릭

**거부 후**:
- 신청 상태가 `rejected`로 변경
- 거부 사유가 신청자에게 표시됨
- 신청자는 `/teams/my-requests`에서 확인 가능

## 경기 관리

### 새 경기 만들기

1. 좌측 메뉴에서 **Matches** 클릭
2. 우측 상단 **"Add Match"** 버튼 클릭
3. 다이얼로그에서 정보 입력:

   **기본 정보**:
   - **경기 날짜**: 캘린더에서 선택
   - **경기 시간**: 22:40 / 23:20 또는 직접 입력
   - **홈 팀**: 드롭다운에서 선택
   - **어웨이 팀**: 드롭다운에서 선택

   **상태 및 결과**:
   - **경기 상태**:
     - `scheduled` (예정) - 기본값
     - `live` (진행 중)
     - `finished` (종료)
     - `cancelled` (취소)
   - **점수**: 상태가 `finished`인 경우만 입력

   **추가 정보**:
   - **Match Sequence**: 고유 식별자 (예: 20250417_001)
   - **게임 비밀번호**: 선택사항

4. **"생성"** 버튼 클릭

### 경기 결과 입력

1. 경기 테이블에서 **"Edit"** 버튼 클릭
2. **경기 상태**를 `finished`로 변경
3. **홈 팀 점수**와 **어웨이 팀 점수** 입력
4. **"수정"** 클릭

**자동 처리**:
- 팀의 승-패 기록 업데이트
- 팀의 득점/실점 누적
- 순위표 자동 계산

### 경기 취소

1. Edit 다이얼로그 열기
2. 상태를 `cancelled`로 변경
3. 저장

### Match Sequence 규칙

형식: `YYYYMMDD_XXX`

- `YYYYMMDD`: 경기 날짜 (예: 20250417)
- `XXX`: 해당 날짜의 경기 순번 (예: 001, 002, ...)

**예시**:
- 2025년 4월 17일 첫 번째 경기: `20250417_001`
- 2025년 4월 17일 두 번째 경기: `20250417_002`

## Excel 일정 업로드

### 1. 템플릿 다운로드

1. 좌측 메뉴에서 **Upload Schedule** 클릭
2. **"Download Template"** 버튼 클릭
3. `kpl_schedule_template.xlsx` 파일 다운로드

### 2. 템플릿 작성

**필수 컬럼**:
- `match_sequence`: 고유 ID (YYYYMMDD_XXX)
- `match_date`: 경기 날짜 (YYYY-MM-DD)
- `home_team`: 홈 팀 이름 (정확히 일치해야 함)
- `away_team`: 어웨이 팀 이름 (정확히 일치해야 함)
- `match_time`: 경기 시간 (HH:MM, 예: 22:40)

**선택 컬럼**:
- `game_password`: 게임 비밀번호

**작성 예시**:
```
match_sequence | match_date | home_team | away_team | match_time | game_password
20250417_001   | 2025-04-17 | Lakers    | Warriors  | 22:40      |
20250417_002   | 2025-04-17 | Celtics   | Heat      | 23:20      |
20250417_003   | 2025-04-17 | Nets      | 76ers     | 22:40      |
```

### 3. 파일 업로드

1. **드래그 앤 드롭** 또는 **클릭하여 파일 선택**
2. 파일 크기 확인 (최대 10MB)
3. **"Parse File"** 버튼 클릭

### 4. 데이터 검증

파싱 후 자동 검증:

**✅ 통과 조건**:
- 모든 필수 컬럼 존재
- 팀 이름이 활성 시즌에 존재
- 날짜/시간 형식 정확
- Match Sequence 중복 없음

**❌ 에러 발생 시**:
- 에러 목록이 빨간색으로 표시됩니다
- Excel 파일을 수정 후 다시 업로드하세요

### 5. 일괄 등록

1. 검증 통과 후 미리보기 테이블 확인
2. **"Upload All (X matches)"** 버튼 클릭
3. 진행 상태 확인
4. 완료 후 성공 메시지

### 다중 경기 업로드 (중요!)

**하루에 여러 경기를 등록할 수 있습니다**:
- 10개 팀 = 하루에 최대 10경기 가능
- 같은 날짜여도 match_sequence가 다르면 OK
- 시간대는 22:40 또는 23:20 권장

**예시 (2025-04-17)**:
```
20250417_001 | 2025-04-17 | Lakers    | Warriors  | 22:40
20250417_002 | 2025-04-17 | Celtics   | Heat      | 22:40
20250417_003 | 2025-04-17 | Nets      | 76ers     | 22:40
20250417_004 | 2025-04-17 | Clippers  | Suns      | 22:40
20250417_005 | 2025-04-17 | Mavericks | Bucks     | 22:40
20250417_006 | 2025-04-17 | Lakers    | Celtics   | 23:20
20250417_007 | 2025-04-17 | Warriors  | Heat      | 23:20
... (최대 10경기)
```

## 자주 묻는 질문

### Q1. 관리자 권한은 어떻게 부여하나요?

Supabase SQL Editor에서 실행:
```sql
UPDATE profiles
SET role = 'admin'
WHERE email = 'user@example.com';
```

### Q2. 시즌을 삭제할 수 있나요?

현재는 삭제 기능이 없습니다. 필요 시 Supabase Dashboard에서 직접 삭제 가능하지만, 관련된 모든 팀과 경기가 함께 삭제되므로 주의하세요.

### Q3. 경기 결과 입력 후 순위표가 업데이트 안 돼요

경기 상태가 `finished`이고 점수가 입력되었는지 확인하세요. 페이지를 새로고침하면 반영됩니다.

### Q4. Excel 업로드 시 "팀을 찾을 수 없습니다" 에러

- Excel의 팀 이름이 정확히 일치하는지 확인
- 대소문자, 띄어쓰기 확인
- 활성 시즌에 팀이 존재하는지 확인

### Q5. 팀 로고가 표시되지 않아요

1. Supabase Storage에서 `team-logos` 버킷이 생성되었는지 확인
2. RLS 정책이 올바르게 설정되었는지 확인 ([STORAGE_SETUP.md](../STORAGE_SETUP.md) 참조)
3. 로고 URL이 올바른지 확인

### Q6. 같은 날짜에 여러 경기를 추가할 수 있나요?

네! Excel 업로드를 사용하면 하루에 10경기까지 추가할 수 있습니다. Match Sequence만 고유하면 됩니다.

### Q7. 경기를 수정했는데 팀 전적이 변경되지 않아요

현재는 경기 결과 수정 시 팀 전적이 자동으로 재계산되지 않습니다. 경기를 삭제하고 다시 생성하거나, Supabase에서 직접 팀의 승-패, 득실점을 수정해야 합니다.

### Q8. 승인한 팀 신청을 취소할 수 있나요?

승인 취소 기능은 없습니다. Teams 페이지에서 해당 팀을 삭제하면 됩니다.

### Q9. 시즌을 변경하면 기존 데이터는 어떻게 되나요?

시즌을 변경해도 기존 데이터는 유지됩니다. 각 시즌은 독립적으로 관리되며, 비활성 시즌의 데이터도 조회 가능합니다.

### Q10. 관리자가 여러 명일 수 있나요?

네, 여러 계정에 `admin` 역할을 부여할 수 있습니다. 각 관리자는 동일한 권한을 갖습니다.

## 💡 팁과 모범 사례

### 시즌 관리
- 시즌 시작 전에 미리 생성하되, 활성화는 개막일에
- 시즌 이름은 명확하게 (예: "2K26 Spring Season")
- Playoff Cutoff는 팀 수에 따라 조정 (10팀이면 5팀)

### 팀 관리
- 팀 생성 시 주장을 반드시 지정
- 로고는 투명 배경 PNG 권장
- 팀 이름은 간결하게 (3~10자)

### 경기 관리
- Match Sequence는 일관된 규칙으로 작성
- 경기 시간은 22:40, 23:20 표준 시간 사용
- 경기 결과는 당일 또는 다음 날 입력

### Excel 업로드
- 템플릿을 수정하여 사용 (컬럼명 변경 금지)
- 팀 이름은 복사-붙여넣기로 정확히 입력
- 한 번에 최대 50경기까지 권장

### 팀 신청 관리
- 신청은 24시간 이내 처리 권장
- 거부 사유는 구체적으로 작성
- 로고 품질 확인 후 승인
